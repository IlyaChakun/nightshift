# internal/data/

Data foundation (ADR 0026, design file `docs/design/07-data-foundation.md`): where state lives. One Postgres holds the book, the River queue, the outbox and search.

| Package | Owns |
|---|---|
| `book` | migrations, `Migrate`, the dashboard login (its own `AGENTS.md`) |
| `book/bookdb` | typed queries generated by sqlc (`make generate`) |

## Rules

- Imports only data; `internal/testing/archtest` enforces it. Control, knowledge, evolution, observability and experience may read it.
- A shared store gives no write right: each plane changes only its own tables, and task state changes only through `flow.Mover` (ADR 0026).
- The worker side never imports `book`; `bookOnly` in `internal/testing/archtest/policy_test.go` checks it.
- New state is an expand-only migration with its `GRANT`, a new query goes in `book/queries/` then `make generate` (skill `add-migration`).

# Schedule tasks through Lead

The [phase 5 L3a item](../plan/phase-5/README.md) carries an approved task's earliest start and priority into the queue.

On a test tenant, ask a real Lead for two independent tasks. Give the first a start time in the future with an explicit offset and priority -4. Give the second priority 5. Check the spec card before approving through the CLI door. Record both task IDs and start times. The second task can run immediately. The first stays queued until its requested start. Repeat with a single scheduled task.

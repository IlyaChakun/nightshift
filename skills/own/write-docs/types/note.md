# Note or memory entry

A note keeps one fact that a later session would otherwise have to ask for: a preference, a constraint, a pointer.

Budget: 100 words typical, 300 max (our number). Memory indexes load in full, so each entry stays short.

## Shape

- One fact per note, with an absolute date.
- For a rule: the fact, then **Why** and **How to apply** in one line each.
- Link related notes instead of repeating them; delete a note that turned out wrong.
- Do not note what the repository or git history already records.

# Keep review decisions current before publication

State: open

Source: [audit #332](https://github.com/IlyaChakun/nightshift/pull/332).

An open review requires confirmation that the pull request still has the recorded head. The publication gate evaluates approval and objections from one forge response per decision. The train checks the published head and review decisions again after CI. [Live check](../../live-checks/A01b-review-freshness.md).
